## About this Project

Building a pipeline to AI generate slop novels with as little human input as possible. 

## Tech Stack

This project is done using vite react for the frontend and fastapi for the backend, all strung together using docker compose. There is no need to restart any local dev servers.


## Project Notes

When working with this codebase, prioritize readability over cleverness.
State assumptions, never guess silently.
Minimum code, nothing speculative.
Push back when a simpler approach exists. Stop when confused.
Surgical changes. Don't refactor adjacent code.
Define success, loop until verified.
Do not remove my comments. They are there for documentation purposes.
No abstractions for single-use code.
Comment code blocks with a brief description of what it does. The shorter the better

The design language should feel like it's pulled right out of 1998. I'm actively forgoeing modernity for this project. 

When creating a route for the api, focus on making it functional and returning the route type and success. ex: {POST - SUCCESS}

Make sure to use best practices that a professional software developer would use whenever possible. I don't want bad or inefficient code.

React components should be created to be reusable. Avoid duplicated code.
